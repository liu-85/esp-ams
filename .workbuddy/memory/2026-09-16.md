## YAO_AMS：改用「1 共享电机 + 4 路电磁离合」方案

用户需求：检查项目结构、完善说明、加 GitHub Actions 自动编译，并把原来
「每通道 2 个 IO 直驱电机」改成「1 个电机 + 4 路电磁离合」，强制同一时刻
只能 1 路离合吸合，按现有换料逻辑编写。

### 关键发现

- 原 `device_processing.py` 的 `material(18,5)` / `(17,16)` / `(23,22)` / `(21,19)`
  用的是**经典 ESP32 的引脚编号**，GPIO22/23 在 ESP32-C3 上**根本不存在**，
  必须重排。ESP32-C3 可用干净引脚只有 GPIO0/1/3/10（外加放弃 JTAG 的 4~7）。
- `now_filament()` 原来是坏的：`dianji_roll()` 结束时 `stop_roll()` 把两个
  方向脚都置 0，紧接着读 `dianji_top.value()` 永远是 0，所以恒返回 0，
  `exchange_fileament` 里「退料」分支其实从未走到过。本次把
  `dianji_top/bottom` 语义修正为到位开关后逻辑才真正成立。
- 项目**没有 main.py**，boot.py 是空壳，板子上其实没有自动启动入口。已补。
- `config.json` / `wifi.dat` 含 WiFi 密码与打印机访问码，之前没有 .gitignore。

### 最终引脚分配（ESP32-C3）

| 信号 | GPIO |
| --- | --- |
| 电机 H桥 IN1 / IN2 | 4 / 5 |
| 电磁离合 1~4 | 6 / 7 / 10 / 3 |
| 状态 LED | 2（strapping 脚，上电默认高，可用） |
