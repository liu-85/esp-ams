WiFi 配置

点开始扫描…

选一个 2.4G 的 WiFi 并填密码。连接成功后设备会记住，以后开机会直接连、 不再重新扫描，同时会自动关闭配置热点 —— 那时这个页面就会从左侧菜单里消失。

打印机 MQTT 配置

配置是否已保存-
加载中…

打印机 IP 在打印机屏幕上「设置 → 网络」里看；访问码在 「设置 → 网络 → 访问码」。序列号是设备 SN，可在同一页找到。
点「保存并连接」会先把配置存进设备，再去尝试连接打印机。 没联网或打印机没开机时连接会失败，但配置已经存好了，开机联网后自动重连。

打印机通道设置 点色块改颜色

默认 4 个通道。通道号要和切片软件里料盘位的编号一致； 颜色只是显示用，方便对应料卷。

硬件调试 共享电机 + 4 路电磁离合

进退响应时间（4 个通道统一用这一个值）

只影响下面这些手动点动按钮，不会改变自动换料时的转动时长。 可填 0.2 ~ 60 秒。存进设备，重启也记得。

同一时刻只会吸合 1 路离合，动作完成后自动全部断开。 按下后立刻开始动作、到点自动停止；动作期间其它点动会被拒绝（不会排队）。

系统升级 网页上传更新包，不用插 USB

用 python tools/make_update_pack.py 生成 .ams 更新包，在这里上传；设备会把里面的文件写进自己的文件系统，然后自动重启。 全部程序逻辑和这个页面都能更新，不需要插 USB、也不用重新配网。
整机固件 BIN（esp32c3-ams-firmware.bin / esp32s3-ams-firmware.bin）不能走这里 —— 板子只有单个应用分区，没有备用分区可以切换，整机升级仍然要 USB 刷写。

升级过程中不要断电。写完之后设备会自动重启，页面会失联十几秒， 重启完成后刷新即可。
